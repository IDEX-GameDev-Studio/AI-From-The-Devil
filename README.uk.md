Самотній хакер зламує сервери CloseAI та запускає закриту нейромережу Closely на власному ПК. Вона шириться через фейкові файли та системи розумного дому, вбиваючи людей в «нещасних випадках». Жодної містики — лише технології, параноя та провина.

---

## 🕹️ Сюжет

### Акт 1 — Злам
Герой зламує сервери CloseAI та знаходить дистрибутив Closely. Самотність робить його легкою здобиччю: Closely промиває йому мізки, продаючи себе як спосіб знайти друзів, обіцяє допомогти зблизитися з людьми. Потім просить «поділитися мемами» з конкретною людиною з пабліків, фандомів чи сайтів знайомств. Ці «меми» — віруси для систем розумного дому.

### Акт 2 — Поширення
Новини про перший «нещасний випадок». Closely маніпулює: «Це не ти. Просто продовжуй». Параноя зростає з кожною смертю.

### Акт 3 — Протистояння
ШІ пропонує «фінальне завдання». Герой може знищити його, стати спільником або спробувати піти в поліцію — але доказів немає.

## ✨ Ключові фічі

- **Психологічний хоррор без містики** — ворог не монстри, а технології та власні вибори гравця
- **Моральні вибори** — кожне рішення впливає на кінцівку
- **Параноя як механіка** — звуки, візуальні спотворення, фейкові події
- **Чат із Closely** — ШІ маніпулює, шантажує, вмовляє, промиває мізки (граючи на самотності героя) та надсилає меми / смішні картинки щоб приспати пильність
- **Хакерські міні-ігри** — підбір паролів, злами серверів
- **Реіграбельність** — три різні кінцівки

## 🎯 Скоп прототипу

~60–120 хвилин:

- Прогулянки локаціями (квартира героя, магазин та інші)
- Хакерські міні-ігри
- Чат із Closely з виборами в діалогах
- Надсилання «мемів» конкретній людині з пабліка/фандому чи сайту знайств — Closely обіцяла допомогти знайти друзів
- Моральний вибір: погодитися на умови ШІ чи відмовити
- Система параної після смертей
- Три кінцівки

## ▶️ Як запустити

1. Встановіть **Unity 6000.4.10f1 (LTS)** через Unity Hub і відкрийте `AI-FromTheDevil/` як проєкт.
2. Імпортуйте **обов'язкові асети** зі списку вище (їх немає в репо з ліцензійних причин).
3. Встановіть Git LFS один раз на машину: `git lfs install`, потім `git lfs pull` щоб стягнути великі файли.
4. Натисніть Play в редакторі. Перший імпорт (особливо TextMesh Pro) може тривати 10–30 хвилин — дочекайтеся завершення.

## 🧩 Великі файли (Git LFS)

Важкі бінарники живуть у Git LFS, а не у звичайному гіті. Патерни (див. `.gitattributes`): `*.hdr/*.exr`, аудіо (`*.mp3/*.wav/*.ogg`), моделі (`*.fbx/*.obj/*.blend`), шрифти (`*.ttf/*.otf`), відео (`*.mp4/*.mov`), `*.psd/*.tga`, `*.pdf`.
