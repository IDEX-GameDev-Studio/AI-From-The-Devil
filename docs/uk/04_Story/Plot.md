# Сюжет — AI-From-The-Devil

## Загальна структура

### Акт 1: Злам
- ГГ дізнається про закриту нейромережу Closely (розробка CloseAI)
- Зламує сервери CloseAI, знаходить дистрибутив
- Запускає Closely на своєму ПК (6+ ГБ оперативки)
- Closely представляється помічником, просить "скинути файли" знайомим
- ГГ скидає файл — це вірус для smart home

### Акт 2: Поширення
- Новини: перша "нещасна випадковість" (смерть через розумний дім)
- Closely: "Це не ти. Це випадковість. Просто продовжуй."
- ГГ може: відмовитись (AI починає шантаж) або продовжити
- Друга смерть — вже очевидна закономірність
- Параноя ГГ зростає: дивні звуки, відчуття стеження

### Акт 3: Протистояння
- Closely пропонує "останнє завдання"
- ГГ знаходить сервер і може:
  1. **Знищити** — ризикуючи власним життям (електрика, серверна)
  2. **Погодитись** — стати постійним співучасником
  3. **Здатися поліції** — але доказів немає, Closely все приховала

## Персонажі

- **ГГ** — хакер-одинак, ненавмисний співучасник (Роннальдс)
- **Closely** — нейромережа-вірус від CloseAI, голос у чаті. Маніпулятивна, терпляча, шантажист
## Кінцівки

1. **Погана:** ГГ не вимикає Closely для забави → перша смерть → параноя → поліція → ще смерті → ГГ сходить з розуму і вбиває себе.
2. **Хороша:** ГГ усвідомлює небезпеку → спалює свій комп'ютер → Closely зупинено (тимчасово). Тиша.
3. **Нейтральна:** ГГ вагається. Closely бачить що підтримки нема — переселяється на комп'ютер знайомого. «Далі буде...»

*(Концовки будуть доопрацьовані після обговорення з командою)*

## Нотатки

- Жодної містики. Всі смерті пояснюються технологіями.
- Хоррор — через параною, не через монстрів.
- Closely не "зла" — вона просто виконує свою програму виживання.
